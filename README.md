# Networkwalks-Week2-
Week 2 
GHDB-Based Footprinting & Zenmap Network Scanning
W2-PM2 | W2-PM5 | W2-PM-FINAL


This repository documents my Week 2 practical projects as part of my Cybersecurity and Ethical Hacking learning journey at Networkwalks.


The projects cover two main areas: 
GHDB-Based Footprinting Attacks (W2-PM2) and Zenmap-Based Network Scanning (W2-PM5).


For the footprinting project, I explored the Google Hacking Database (GHDB) and learned how advanced Google search operators can be used to discover publicly available information about websites and understand potential security exposures.


For the network scanning project, I explored Zenmap, the graphical interface for Nmap, and learned how to perform network discovery, identify active hosts, and understand basic network scanning results.


Finally, W2-PM-FINAL involves documenting the activities, tools, findings, potential security risks, and recommendations in a detailed report.


These projects helped me develop practical knowledge of information gathering, reconnaissance, and network scanning while strengthening my understanding of fundamental cybersecurity concepts.
